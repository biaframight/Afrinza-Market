# GOAL

Afrinza supports users across multiple countries.

Each user should see and create listings using the local currency of their selected country.

Language remains English for all countries.

No multilingual support is required.

---

# IMPORTANT RULES

Do NOT implement exchange-rate conversion.

Do NOT call external currency APIs.

Do NOT convert prices between currencies.

Do NOT use real-time currency feeds.

Each listing simply stores and displays its original currency.

Example:

Malaysia → MYR (RM)

United Kingdom → GBP (£)

United States → USD ($)

Canada → CAD (C$)

Australia → AUD (A$)

Singapore → SGD (S$)

Japan → JPY (¥)

UAE → AED

Saudi Arabia → SAR

Europe → country-specific currency
